# Repeating Table Headers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repeat computed table header groups on every continuation page while reserving their height in table body fragmentation.

**Architecture:** Add a thin table coordinator around the existing `fragment_block_subtree`. The coordinator classifies Blitz's table cells from computed `DisplayInside`, enables the existing `RowState` for flattened table rows, fragments body cells with a reduced virtual page height, maps body geometry back while preserving `is_repeat`, and clones the complete header geometry. The renderer continues consuming geometry, but split table frames and clips use the current fragment height.

**Tech Stack:** Rust, Blitz DOM/Taffy table layout, Stylo 0.8 computed display values, existing `PaginationGeometryTable`, Krilla PDF rendering, `lopdf` smoke assertions, existing `fulgur-vrt` PDF goldens, Cargo test/fmt/clippy.

```rust
#[test]
fn table_header_repeats_and_reserves_body_space() {
    let html = r#"
        <html><head><style>
          html, body { margin: 0; padding: 0; }
          table { border-spacing: 0 6px; width: 100px; }
          th, td { box-sizing: border-box; height: 30px; padding: 0; }
        </style></head><body>
          <table id="table">
            <thead><tr><th id="header"><div id="header-block">HEADER</div></th></tr></thead>
            <tbody>
              <tr><td id="row-1">1</td></tr>
              <tr><td id="row-2">2</td></tr>
              <tr><td id="row-3">3</td></tr>
              <tr><td id="row-4">4</td></tr>
              <tr><td id="row-5">5</td></tr>
            </tbody>
          </table>
        </body></html>
    "#;
    let mut doc = parse(html, 200.0);
    let table_id = find_by_id(&doc, "table").unwrap();
    let header_id = find_by_id(&doc, "header").unwrap();
    let header_block_id = find_by_id(&doc, "header-block").unwrap();
    let first_row_id = find_by_id(&doc, "row-1").unwrap();
    let last_row_id = find_by_id(&doc, "row-5").unwrap();
    let body_origin = doc.get_node(first_row_id).unwrap().final_layout.location.y;

    let geometry = run_pass(&mut doc, 90.0);
    let table_pages: Vec<u32> = geometry[&table_id]
        .fragments
        .iter()
        .map(|f| f.page_index)
        .collect();
    let header = &geometry[&header_id];
    let header_pages: Vec<u32> = header.fragments.iter().map(|f| f.page_index).collect();
    let header_block = &geometry[&header_block_id];

    assert!(header.is_repeat, "header geometry must represent full redraws");
    assert_eq!(header_pages, table_pages, "header must cover every table page");
    assert!(header_block.is_repeat, "header descendants must redraw in full");
    assert_eq!(
        header_block.fragments.iter().map(|f| f.page_index).collect::<Vec<_>>(),
        table_pages,
        "header descendants must cover every table page"
    );
    assert!(geometry[&last_row_id].fragments.last().unwrap().page_index > 0);

    for (&node_id, node_geometry) in &geometry {
        if node_id == header_id || node_id == table_id {
            continue;
        }
        for fragment in node_geometry.fragments.iter().filter(|f| f.page_index > 0) {
            if [
                first_row_id,
                find_by_id(&doc, "row-2").unwrap(),
                find_by_id(&doc, "row-3").unwrap(),
                find_by_id(&doc, "row-4").unwrap(),
                last_row_id,
            ]
            .contains(&node_id)
            {
                let table_top = geometry[&table_id]
                    .fragments
                    .iter()
                    .find(|f| f.page_index == fragment.page_index)
                    .unwrap()
                    .y
                    .to_f32();
                assert!(
                    fragment.y.to_f32() + 0.5 >= table_top + body_origin,
                    "body node {node_id} overlaps repeated header: {fragment:?}"
                );
            }
        }
    }
}
```

Implement `repeating_table_header(doc, table_id, child_depth)` as a read-only walk of raw `node.children`, matching Blitz 0.2.4's `layout/table.rs::collect_table_cells`. `child_depth` is the absolute fragmenter depth of the table's direct children, not a fresh metadata-local counter. Before walking, return `None` unless the candidate parent itself has computed `DisplayInside::Table`. Use `node.primary_styles().map(|s| s.clone_display().inside())`; this is the Stylo 0.8 smoke check. Recurse through `TableHeaderGroup`, `TableRowGroup`, `TableFooterGroup`, `TableRow`, and `Contents`; classify `TableCell`; stop cell discovery at nested `Table`. Do not mix in `layout_children`: for a table it is already a flattened cell list and has lost header/body ancestry.

```rust
fn collect_table_cells(
    doc: &BaseDocument,
    node_id: usize,
    in_header: bool,
    header_cells: &mut Vec<usize>,
    body_cells: &mut Vec<usize>,
    depth: usize,
) {
    if depth >= crate::MAX_DOM_DEPTH {
        return;
    }
    let Some(node) = doc.get_node(node_id) else { return };
    let Some(inside) = node.primary_styles().map(|s| s.clone_display().inside()) else {
        return;
    };
    match inside {
        DisplayInside::TableHeaderGroup => {
            for &child_id in &node.children {
                collect_table_cells(doc, child_id, true, header_cells, body_cells, depth + 1);
            }
        }
        DisplayInside::TableRowGroup
        | DisplayInside::TableFooterGroup
        | DisplayInside::TableRow
        | DisplayInside::Contents => {
            for &child_id in &node.children {
                collect_table_cells(doc, child_id, in_header, header_cells, body_cells, depth + 1);
            }
        }
        DisplayInside::TableCell => {
            if in_header {
                header_cells.push(node_id);
            } else {
                body_cells.push(node_id);
            }
        }
        DisplayInside::Table => {}
        _ => {}
    }
}
```

Start the recursive classifier at each raw child of the table with `in_header = false` and `depth = child_depth`:


Retain only the emitted cell IDs and geometry values. The temporary header geometry created during fragmentation is the source of truth for geometry-emitting descendants inside each classified cell, so no root or subtree-ID set is stored. Compute:

```rust
let header_top_px = header_cell_ids
    .iter()
    .map(|id| doc.get_node(*id).unwrap().final_layout.location.y)
    .reduce(f32::min)?;
let header_bottom_px = header_cell_ids
    .iter()
    .map(|id| {
        let layout = doc.get_node(*id).unwrap().final_layout;
        layout.location.y + layout.size.height
    })
    .reduce(f32::max)?;
let body_origin_px = body_cell_ids
    .iter()
    .map(|id| doc.get_node(*id).unwrap().final_layout.location.y)
    .reduce(f32::min)?;
let band_height_px = header_bottom_px.max(body_origin_px);
```

Return `None` unless all three values are finite, both cell lists are non-empty, and `band_height_px > 0.0`.

- For every body node, add `band_height_px` to fragment y.

Put cloning in this helper so the aggregate budget can be tested without constructing one million DOM nodes:

```rust
fn append_repeated_header_fragments(
    geometry: &mut PaginationGeometryTable,
    template: &PaginationGeometryTable,
    table_pages: &[(u32, f32)],
    first_table_top: f32,
    remaining_budget: &mut usize,
) {
    let repeats = table_pages.len() > 1;
    for (&node_id, source) in template {
        let target = geometry.entry(node_id).or_default();
        target.is_repeat |= repeats;
        target.fragments.extend(source.fragments.iter().cloned());
    }
    if !repeats {
        return;
    }

    let fragments_per_header: usize = template
        .values()
        .map(|entry| entry.fragments.len())
        .sum();
    for &(page_index, table_top) in &table_pages[1..] {
        if *remaining_budget < fragments_per_header {
            log::warn!("repeated table header fragment budget exhausted");
            return;
        }
        for (&node_id, source) in template {
            for fragment in &source.fragments {
                let mut repeated = fragment.clone();
                repeated.page_index = page_index;
                repeated.y = (table_top + fragment.y.to_f32() - first_table_top).as_px();
                geometry.entry(node_id).or_default().fragments.push(repeated);
            }
        }
        *remaining_budget -= fragments_per_header;
    }
}
```

Pass the coordinator's `remaining_repeat_budget` directly as the helper's `remaining_budget`; never initialize a table-local counter. Reserve the complete template-fragment count before cloning a continuation page, so the budget can drop a whole repeated header but never half of one. Emit `log::warn!` when the pass budget is insufficient. Never drop body geometry or mark table/body nodes as repeat geometry.
