# krilla 0.8 Migration Implementation Plan

**Goal:** Migrate fulgur from krilla/krilla-svg 0.7 to 0.8, keeping inline `<svg>` rendering working.

**Architecture:** Bump krilla 0.7.0→0.8.2, krilla-svg 0.7.0→0.8.1, and fulgur's usvg 0.45→0.47 (to share types with krilla-svg 0.8.1). Adapt the changed `Configuration`/`Validator` API. For inline `<svg>`, stop extracting blitz-dom's usvg-0.45 tree (kept only for Taffy intrinsic sizing) and instead re-parse the element's original markup via `node.outer_html()` with fulgur's usvg 0.47 for rendering.

**Tech Stack:** Rust, krilla 0.8.2, krilla-svg 0.8.1, usvg 0.47, blitz-dom 0.2.4.

**Tracking:** beads `fulgur-dan7`.

**Step 3: Implement `render_svg_markup`** (module-level `pub` fn in `svg.rs`)

```rust
/// Parse SVG `markup` into a usvg 0.47 tree for rendering via krilla-svg.
///
/// Inline `<svg>` is parsed twice on purpose: blitz-dom parses it into a
/// usvg-0.45 tree used only for Taffy intrinsic sizing (its `svg` feature),
/// and krilla-svg 0.8 needs a usvg-0.47 tree, so we re-parse the original
/// markup here. Fonts mirror blitz-dom's `parse_svg` (system fonts; see the
/// determinism caveat in CLAUDE.md / issue fulgur-a8s) so the 0.47 re-parse
/// matches current rendering. Bundled-font determinism is a follow-up.
pub fn render_svg_markup(markup: &str) -> Option<usvg::Tree> {
    let mut fontdb = usvg::fontdb::Database::new();
    fontdb.load_system_fonts();
    let opts = usvg::Options {
        fontdb: std::sync::Arc::new(fontdb),
        ..usvg::Options::default()
    };
    usvg::Tree::from_data(markup.as_bytes(), &opts).ok()
}
```

**Step 4: Rewire `convert_svg`** — replace the `extract_inline_svg_tree` call (`convert/replaced.rs`). The caller (`replaced.rs:26`) already gates on `tag == "svg"`, so no detection is needed here.

```rust
fn convert_svg(
    _ctx: &ConvertContext<'_>,
    node: &Node,
    assets: Option<&AssetBundle>,
    out: &mut crate::drawables::Drawables,
) -> bool {
    // Re-parse the original <svg> markup with fulgur's usvg 0.47 (blitz-dom's
    // parsed tree is usvg 0.45, incompatible with krilla-svg 0.8).
    let Some(tree) = crate::svg::render_svg_markup(&node.outer_html()) else {
        return false;
    };

    let (content_w, content_h, opacity, visible) =
        maybe_insert_block_for_replaced(node, assets, out);
    out.svgs.insert(
        node.id,
        crate::drawables::SvgEntry {
            tree: std::sync::Arc::new(tree),
            width: content_w.as_pt(),
            height: content_h.as_pt(),
            opacity,
            visible,
        },
    );
    true
}
```
