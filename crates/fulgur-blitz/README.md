# fulgur-blitz

The [Blitz](https://github.com/DioxusLabs/blitz)-based layout and PDF rendering
backend for [fulgur](https://crates.io/crates/fulgur), an HTML/CSS to PDF
converter.

Most users should depend on the [`fulgur`](https://crates.io/crates/fulgur)
crate instead, which re-exports this backend under stable paths.
