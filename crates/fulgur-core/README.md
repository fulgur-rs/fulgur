# fulgur-core

Backend-independent building blocks for [fulgur](https://crates.io/crates/fulgur),
an HTML/CSS to PDF converter: page and PDF configuration, the asset bundle,
unit newtypes, the error type, image format handling, and PDF inspection.

Most users should depend on the [`fulgur`](https://crates.io/crates/fulgur)
crate instead, which re-exports these items under stable paths.
